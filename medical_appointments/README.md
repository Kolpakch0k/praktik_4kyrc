# Запись пациентов на прием

Desktop-приложение на Python 3.11+, CustomTkinter, календарём tkcalendar и MySQL 8. Включает справочники пациентов, врачей и специализаций, запись с проверкой слота, расписание, отмену и отчет за период.

## Установка и запуск (Windows)
1. Установите Python 3.11+ и MySQL Server 8.
2. В MySQL Workbench выполните `database/init.sql`.
   Если база уже создана по старой версии скрипта, один раз выполните `database/migrate_active_slot.sql`, чтобы отменённые записи не мешали повторно занимать освободившееся время.
3. Скопируйте `.env.example` в `.env` и укажите параметры локальной БД.
4. В папке проекта выполните `py -m venv .venv`, затем `.venv\Scripts\activate`.
5. Установите библиотеки: `pip install -r requirements.txt`.
6. Запустите: `python main.py`.

## Сценарии
Создайте специализацию, затем врача с соответствующим ID, пациента и запись. Справочники поддерживают создание, изменение, удаление; запрет удаления связанных записей задан внешними ключами. Для тестового сценария создайте запись на будущее и повторите тот же слот: второй запрос будет отклонен уникальным индексом. Отмена меняет статус, запись остается в истории и освобождает слот. Для отчета укажите обе границы периода.

В таблице записи врачей и пациентов для связей указываются числовые ID. Номер телефона и обязательные поля должны быть заполнены. Даты выбираются в календаре и отображаются в формате `ДД.ММ.ГГГГ`; прошедшие даты приема недоступны. В полях даты по умолчанию стоит сегодняшняя дата. Время вводится как `ЧЧ:ММ`.
